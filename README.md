## About the Series

**Avatar: The Last Airbender** is an animated TV series. It was created by Michael Dante DiMartino and Bryan Konietzko. It was shown on Nickelodeon from **2005 to 2008**.

> A young boy named Aang must learn all four elements and help end a long war.

## Main Characters

1. **Aang** - the Avatar and the last Airbender
2. **Katara** - a Waterbender and Aang's close friend
3. **Sokka** - a smart fighter and the team's planner
4. **Toph** - a strong Earthbender
5. **Zuko** - a prince who changes during the story
